# Typed HIR for Briev — 2026-11-02

**Status:** active. Pre-release compiler; public syntax and ABI remain frozen while
internal semantics move to a typed normalized HIR.

## Decision

Keep the parser AST as the syntax tree. Add a typed HIR between frontend
normalization and analyses/codegen.

```text
source
  -> parser AST
  -> imports + inline stages + plugins + composites/desugar
  -> typecheck
  -> typed HIR
  -> semantic fact passes
  -> lowering plans
  -> backends
```

HIR becomes the single semantic source. Backends eventually stop matching raw
`TopLevel`/`Expr` syntax. The parser AST remains the place for grammar fidelity,
spans from the source, and syntactic diagnostics.

## Problems this removes

- `needs_state` has a Rust reference and a Briev pass with duplicated traversal.
- Cast semantics are re-derived in backend (`Expr::Cast(inner, Type)` loses the
  protocol path; a C boundary bug came from `CStr → String → Int`).
- Exports/plugins/members survive into late phases (`TopLevel::Export`,
  `TypeDefOperator`, `PluginIntercept`), causing skipped plugins and backend
  panics.
- Destination IDs come from statement paths and collided (`expr_serial` fix).
- Collection inserts, state stores, object fields, and match projections are
  syntax shapes reinterpreted by lowering, which produced the List<Result> and
  JsonValue nested-array bugs.
- Enum/object metadata is split across AST shape, layout planners, and backend
  maps.

## HIR shape

```text
src/hir/
  mod.rs
  ids.rs          — NodeId, ItemId, DefId, ValueId, Span
  program.rs      — HirProgram, items, symbols, callable index
  expr.rs         — typed expressions, explicit calls/casts/constructors
  stmt.rs         — typed statements, loops, guards, returns
  pattern.rs      — typed match patterns and bindings
  lower.rs        — typed AST + environment -> HIR
  normalize.rs    — exports, plugins, desugar-only syntax normalization
  verify.rs       — structural/type/ownership invariants
  facts/          — state, escape, liveness, destination facts
```

Invariants:

1. Every expression/statement/pattern has `NodeId + Span`.
2. Every expression has a resolved `Type`/`TypeId`; no backend Int fallback.
3. Calls name resolved callables, not strings requiring late lookup.
4. Casts carry an explicit `via` protocol path from the casting graph.
5. Enum constructors name `(enum type, variant, tag)`.
6. Match arms name projections and binding ownership directly.
7. Collection inserts, state stores, object fields, tuple stores, returns, and
   FFI boundaries are explicit sink nodes.
8. Exports are callable metadata; no `TopLevel::Export` wrapper remains.
9. No `PluginIntercept` or `StageBlock` reaches HIR; unresolved constructs are
   frontend diagnostics with spans.
10. HIR is deterministic and independent of HashMap iteration order.

### H2 — Move ownership/enum/object facts to HIR

- Collection insert/state/object/tuple/return sinks explicit.

- Port `needs_state`, `defn_liveness`, `storage_class`, `boundary_ownership`,

- Delete duplicate AST walkers after parity.
- Implement generic callable txn specialization on HIR substitution.
- Gate: needs_state parity, generic txn fixture, full corpus.

### H4 — Move backend consumption

- Backend reads HIR types/symbols/casts/constructors/patterns/sinks.
- Migrate emitters family-by-family: expressions/calls/casts, statements/loops/
  patterns, enums/objects/collections, exports/FFI/special backends.
- Gate after each family: exact IR A/B, runtime, I11, wasm/JS.

### H5 — Retire legacy paths

- Remove raw-AST backend pattern matches and ad-hoc maps.
- Delete export/plugin wrappers from backend paths.
- Delete path-derived IDs, duplicate walkers, compatibility adapters.
- Parser AST becomes frontend-only.
- Publish compile-time/runtime before/after evidence.

## Safety rules

- HIR lowering is verified against the typed AST before consumers switch.
- Every slice preserves IR until explicitly optimizing.
- No HIR node may omit type/ownership facts and rely on backend fallback.
- Missing information is a frontend diagnostic, not a backend panic.
- Public ABI, runtime ABI, source syntax, persisted layouts stay frozen.
- Performance work waits until each HIR slice is IR-equivalent.
