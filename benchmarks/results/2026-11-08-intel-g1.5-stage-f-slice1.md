# Intel G1.5 Stage F — slice 1 (OpenCL projection) implementation record

**2026-11-08.** First vertical slice of the Stage F projection, per the design
constraints in `2026-11-08-intel-g1.5-stage-f-design.md`.

## What landed

- `SpirvFlavor { Vulkan, OpenCL }` on `SpirvBuilder`:
  - OpenCL: `Kernel` + `Addresses` + `Int8` capabilities,
    `OpMemoryModel Physical64 OpenCL`, entry model `Kernel`, entry name
    `briev_kernel` (the flavor owns model and name in `set_entry_point`).
  - Vulkan: unchanged (`Shader`, `Logical/GLSL450`, `GLCompute`, caller name).
- OpenCL state ABI: the state is kernel argument 0 (`ptr CrossWorkgroup u8`)
  plus the dispatch bound `n` (u64), created as `OpFunctionParameter`s of the
  entry function. Field access lowers through byte-offset
  `OpInBoundsPtrAccessChain` + pointer bitcast using the SAME `projection_offsets`
  layout as Vulkan (no Block/Offset decorations — they require Shader).
  Vec4 FMA groups use 16-byte group offsets on the same base.
- Scope boundaries (capability errors, Vulkan fall-through): GEMM
  (tensor/tiled/coopmat), image bindings, and f16 state stay Vulkan-only for
  this slice.
- Dual image through the descriptor:
  - `BrievKernelDesc` appends `opencl_spirv` / `opencl_size` (offset 96/104,
    sizeof 112; C header + Rust mirror + LLVM struct + ABI pins updated).
  - `.abv` runner C emission carries `ko<N>` arrays + descriptor args.
  - `.bv` LLVM path embeds `@briev_kernel_<txn>_ocl` when the image exists.
  - `accel_rt::kernel_blob` prefers the OpenCL image for the `levelzero` and
    `opencl` drivers; absent → Vulkan blob fall-through.

## Verification (2026-11-08, local toolchain)

- New test `test_opencl_flavor_projection_on_scale_kernel`: structural
  assertions + `spirv-val` PASS. Module head:
  `Kernel/Addresses/Int8/Int64/Float64/GroupNonUniform(+Arithmetic)`,
  `Physical64 OpenCL`, `OpEntryPoint Kernel %.. "briev_kernel"`,
  `OpFunctionParameter %_ptr_CrossWorkgroup_uchar` (+ `%ulong`), LocalSize
  preserved, no `DescriptorSet`/`Binding`/`Block`.
- `.abv` artifact (`examples/gpu/scale.abv`): emitted `ko0` blob = 896 bytes;
  extracted and `spirv-val` PASS. Runner C compiles against the updated
  header (`cc -I lib/runtime -c scale_runner.c`).
- `.bv` artifact (`benchmarks/intel_ptl/g0_elem.bv`, LLVM path): embedded
  `@briev_kernel_selfadd_ocl` = 1152 bytes; extracted and `spirv-val` PASS
  (Kernel args state+n, entry `briev_kernel`, no descriptors).
- `cargo test --lib`: 3557 passed, 0 failed.
